# COLOR.M 마음색 그림책 교실 (4회차 오프라인 수업용)

마음색 그림책 메이커를 **4회 수업**에 맞춰 회차별 메이커 4개로 나눈 버전입니다.
설치 없이 브라우저에서 동작하며, 입력 내용은 서버로 보내지 않고 브라우저에만 저장됩니다.
결제·랜딩·갤러리 기능은 넣지 않았습니다.

| 회차 | 폴더 | 단계 |
|---|---|---|
| 1회 | `maker-1/` | 01 기획(마음색 시작) · 02 이야기 · 03 스토리보드 |
| 2회 | `maker-2/` | 04 캐릭터 · 05 장면 |
| 3회 | `maker-3/` | 편집 1 그림책 정리(순서·글·수정 요청문·PDF) · 편집 2 캔바 편집 안내 |
| 4회 | `maker-4/` | 06 표지 · 07 출판 정보 |

- 각 메이커는 따로 씁니다 (다른 회차로 가는 버튼·링크 없음). 메이커 시작: `maker-N/index.html` · 전체 결과: `maker-4/summary.html`
- `index.html`은 선생님용 운영 안내입니다 (검색 제외 · 메이커에서 링크 없음): 회차별 주소 복사, 진행 순서·준비물, 학생 안내 문구, 자주 생기는 일.
- 공통 코드: `shared/` (회차 구성은 `colorm.js`의 `SESSIONS`·`STEPS`, 회차 안내 문구는 `session.js`)
- 저장은 메이커마다 따로입니다 (`colorm_class_s1_` ~ `colorm_class_s4_`). 회차가 바뀌면 지난 회차에서 저장한 작업파일(.json)을 불러와야 이어집니다.
